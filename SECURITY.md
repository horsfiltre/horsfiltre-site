# Politique de sécurité

## Signaler une vulnérabilité

Écrivez à **contact@horsfiltre.fr** avec l'objet « Sécurité ». N'ouvrez pas de ticket public : une faille décrite publiquement avant correction expose nos utilisateurs.

Merci d'indiquer la page ou le composant concerné, les étapes pour reproduire le problème et son impact estimé.

## Nos engagements

- Accusé de réception sous 72 heures.
- Évaluation et plan de correction communiqués sous 7 jours.
- Mention de votre contribution après correction, si vous le souhaitez.

## Périmètre

Ce dépôt contient le site public de Hors Filtre. Il ne contient ni secret, ni donnée personnelle, ni accès à une infrastructure : les identifiants de déploiement sont stockés uniquement dans les environnements GitHub protégés.
